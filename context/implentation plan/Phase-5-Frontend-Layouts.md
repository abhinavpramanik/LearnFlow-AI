# Phase 5 - Frontend Layouts & Shared Components
## Project: LearnFlow AI

### Goals
- Build the core user interface framework and shared components.

### Tasks
1. **Global Layout:**
   - Create responsive sidebar, header, and main content area.
   - Implement navigation menus based on user role.
2. **Shared Components:**
   - Build reusable UI elements: Buttons, Inputs, Cards, Modals, Tables, Spinners.
   - Ensure styling consistency using Tailwind CSS.
3. **Dashboard Scaffolding:**
   - Create basic placeholder views for the main dashboard and core modules (Profiles, Journeys, Tickets).
