# Phase 1 - Initialization
## Project: LearnFlow AI

### Goals
- Set up the foundational environment for both frontend and backend.
- Establish the initial project structure.

### Tasks
1. **Initialize Monorepo:** Create `client` and `server` directories.
2. **Backend Setup:**
   - Initialize Node.js and Express in the `server` directory.
   - Configure environment variables (`dotenv`).
   - Set up MongoDB connection (`mongoose`).
   - Create basic Express server structure (routes, controllers, models, config).
3. **Frontend Setup:**
   - Initialize React with Vite in the `client` directory.
   - Configure Tailwind CSS.
   - Set up React Router.
   - Create initial scaffolding (App, main, etc.).
4. **Git Repository:** Initialize git, create `.gitignore`.
