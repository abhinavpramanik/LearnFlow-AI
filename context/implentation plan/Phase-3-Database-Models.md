# Phase 3 - Core Database Models
## Project: LearnFlow AI

### Goals
- Define and implement the core schemas for the application in MongoDB.

### Tasks
1. **Profile & Journey Models:**
   - Implement `Profile` schema for unified customer view.
   - Implement `Journey` schema for tracking learning paths.
2. **Learning Models:**
   - Implement `Skill`, `Course`, `Enrollment`, `Assessment`, and `Certification` models.
3. **Operational Models:**
   - Implement `Ticket` schema for service requests.
   - Implement `Interaction` and `Message` models for conversation history.
   - Implement `Campaign` and `Segment` models for marketing.
4. **AI & System Models:**
   - Implement `Recommendation`, `Approval`, `Override`, and `AiRun` models.
   - Implement `AuditLog` and `Notification` models.
