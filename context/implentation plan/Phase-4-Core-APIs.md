# Phase 4 - Core REST APIs
## Project: LearnFlow AI

### Goals
- Develop robust backend endpoints to serve the business logic and frontend needs.

### Tasks
1. **CRUD Endpoints:**
   - Users and Profiles management.
   - Journeys and Learning progress.
   - Tickets and Interactions.
   - Campaigns and Segments.
2. **Validation & Error Handling:**
   - Implement request validation using Zod.
   - Create central error handling middleware.
3. **Logging & Auditing:**
   - Add audit logging for sensitive actions (CRUD operations on key entities).
